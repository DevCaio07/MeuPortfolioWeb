## 👨‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e venho construindo minha trajetória na área de desenvolvimento de software, com foco principalmente em **Back-end com Java**.

Tenho interesse em desenvolver aplicações completas, trabalhando desde a construção de interfaces até APIs e integração com bancos de dados.

Atualmente, venho aprofundando meus conhecimentos em **Java, Spring Boot, APIs REST, bancos de dados e desenvolvimento web**.

## 🚀 Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd portfolio
```

Depois, basta abrir o arquivo:

```text
index.html
```

Também é possível utilizar o **Live Server** no VS Code para visualizar o projeto durante o desenvolvimento.
